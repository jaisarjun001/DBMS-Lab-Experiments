# Experiment 3: Aggregate Functions and SQL Queries

## Aim
To create an Employee-Department-Project database schema, insert sample data containing at least 30 employees, 5 departments and 8 projects, and execute queries using Selection, Projection, Aggregate Functions, GROUP BY, HAVING, CASE Expressions, and ORDER BY.

## Theory
SQL is used to create, manage, and retrieve data from relational databases.

- **Selection:** Retrieves rows that satisfy a condition using `WHERE`.
- **Projection:** Retrieves specific columns from a table.
- **Aggregate Functions:** `COUNT()`, `SUM()`, `AVG()`, `MAX()`, and `MIN()` perform calculations on data.
- **GROUP BY:** Groups rows with the same values.
- **HAVING:** Filters groups based on a condition.
- **CASE:** Categorizes data based on specified conditions.
- **ORDER BY:** Sorts query results in ascending or descending order.

## Procedure
1. Create the `Company_DB` database.
2. Create Department, Project, and Employee tables.
3. Insert sample data into the tables.
4. Execute selection and projection queries.
5. Execute aggregate functions and grouping queries.
6. Apply HAVING and CASE expressions.
7. Sort results using ORDER BY.

## Output
The database tables are created, sample records are inserted, and SQL queries display employee information, salary statistics, department-wise summaries, and sorted results.
