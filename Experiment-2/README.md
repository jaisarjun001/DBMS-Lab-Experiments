# Experiment 2: E-Commerce Database

## Aim
To design and implement an e-commerce database using SQL.

## Theory
A relational database stores data in tables consisting of rows and columns. SQL is used to create tables, insert records, and retrieve data.

**Concepts Used:**
- Primary Key and Foreign Key
- NOT NULL and UNIQUE constraints
- CREATE DATABASE and CREATE TABLE
- INSERT INTO and SELECT statements
- Referential integrity

## Procedure
1. Create the database `ecommerce_db`.
2. Create the required tables.
3. Define primary keys and foreign keys.
4. Insert sample records into the tables.
5. Execute `SHOW TABLES` to display the tables.
6. Execute SELECT queries to display records.

## Output
The database tables are created and sample records are displayed using SQL queries. Refer to `output.png` for screenshots of the execution results.

## Conclusion
The experiment demonstrates database creation, table creation, data insertion, constraints, and data retrieval using SQL.
