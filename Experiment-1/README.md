# Experiment 1: E-commerce ER Diagram

## Aim
To design an ER diagram for an Indian e-commerce platform with entities Customer, Product, Order, Order Item, Seller, Category, Payment, Delivery and Address.

## Concepts Used
- Primary keys
- Composite attributes
- Multivalued attributes
- Weak entities
- Specialization
- Participation constraints

## Source Code
The ER diagram is designed manually using ER modeling concepts.

## Output
The ER diagram represents the entities, attributes and relationships of the e-commerce platform.
